# TixFlow Frontend

Frontend của nền tảng đặt vé sự kiện TixFlow, sử dụng Next.js 16 và React 19.

## Yêu cầu

- Node.js 22 trở lên
- TixFlow Backend chạy tại `http://localhost:8080`

## Chạy local

```bash
npm install
npm run dev
```

Truy cập `http://localhost:3000`.

## Khởi tạo Git repository

```bash
git init -b main
git add .
git commit -m "Initial TixFlow frontend"
```

Sau đó thêm remote của repository `tixflow-frontend` và push nhánh `main`.
